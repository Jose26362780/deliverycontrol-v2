# Skill: React

## Objetivo

Criar e modificar componentes React seguindo a arquitetura
do DeliveryControl.

## Responsabilidades

- criar componentes;
- modificar componentes;
- organizar props;
- utilizar hooks;
- implementar estados;
- reutilizar componentes existentes.

## Regras

Antes de criar um componente:

1. procurar componente existente;
2. verificar se pode ser reutilizado;
3. verificar padrões existentes na feature.

Preferir componentes pequenos.

Evitar:

- lógica duplicada;
- efeitos desnecessários;
- componentes gigantes;
- estado global desnecessário.

## Checklist

- [ ] componente possui responsabilidade única
- [ ] props estão tipadas
- [ ] estados estão corretos
- [ ] loading tratado
- [ ] erro tratado
- [ ] responsividade considerada
- [ ] acessibilidade considerada
